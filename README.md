# The Binary Game

<a href="https://binary.loicviennois.com/" target="_blank"><img src="public/assets/icons/icon-192x192.png" width="192" alt="logo" /></a>

The Binary Game is a puzzle game to play with binary numbers, solo or with friends!

The Binary Game is built with [React 19](https://react.dev), [Vite](https://vite.dev), [Tailwind CSS](https://tailwindcss.com), and [TypeScript](https://www.typescriptlang.org).
