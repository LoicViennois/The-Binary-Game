# The Binary Game

<a href="https://binary.loicviennois.com/" target="_blank"><img src="public/icons/icon-192x192.png" width="192" alt="The Binary Game logo" /></a>

The Binary Game is a fast-paced puzzle for learning binary numbers, solo or with friends.

## Stack

- React 19 and TypeScript
- Vite
- Tailwind CSS 4
- Vite PWA

## Development

```bash
pnpm install
pnpm dev
```

Quality checks:

```bash
pnpm lint
pnpm test
pnpm build
```
